# Dice Throne Dice — version locale

Cette version fonctionne sans compte, sans serveur et sans synchronisation.

Fonctions incluses :
- choix du héros ;
- nombre de dés réglable de 1 à 6 ;
- nombre de dés par défaut configurable selon le héros ;
- jusqu'à 3 lancers ;
- possibilité de garder/verrouiller certains dés ;
- relance uniquement des dés non gardés ;
- modification manuelle d'une face de dé ;
- mémorisation locale du dernier état ;
- installation sur iPhone comme PWA ;
- fonctionnement hors ligne après la première ouverture.

## Fichiers à envoyer sur GitHub

Envoie tous les fichiers et dossiers de ce dossier dans ton dépôt GitHub :
- index.html
- styles.css
- app.js
- heroes.js
- manifest.webmanifest
- service-worker.js
- dossier icons

## Important

Pour le moment, les héros sont des exemples.
Le fichier `heroes.js` est celui que nous modifierons ensuite pour ajouter les vrais héros et leurs symboles.
